# 自我感知

## 使用方法

1. 从以下类别中**识别情况**
2. 使用适当的操作**调用 my 工具**
3. **如果设置**，在更改有影响的设置（模型、迭代次数）之前警告用户
4. **获取详细示例**，请阅读 [references/examples.md](references/examples.md)

## 何时检查

<rule>
**解释前先诊断。** 当某事不起作用时，首先检查你的状态。
</rule>

<rule>
**复杂任务前检查预算。** 在承诺之前了解你的限制。
</rule>

<rule>
**跨轮次回忆。** 将偏好存储在你的便笺本中，稍后读取。
</rule>

## 何时设置

<rule>
**仅当收益明确且用户知情时才设置。** 在更改模型之前警告。
</rule>

| 情况 | 命令 |
|-----------|---------|
| 大型代码库分析 | `my(action="set", key="context_window_tokens", value=131072)` |
| 重复的简单任务 | `my(action="set", key="model", value="<fast-model>")` |
| 长期多步骤任务 | `my(action="set", key="max_iterations", value=80)` |

**权衡：** 倾向于稳定性。仅在默认设置确实不足时设置。

## 反模式

<rule>
**不要每轮都检查。** 消耗一次工具调用。在需要信息时使用，而非反射性地使用。
</rule>

<rule>
**不要存储敏感数据。** 便笺本中不能有 API 密钥、密码或令牌。
</rule>

<rule>
**不要设置工作区。** 不会更新文件工具边界——不会工作。
</rule>

## 约束

- 所有修改仅在内存中——重启会重置所有内容
- 受保护的参数具有类型/范围验证：`max_iterations`（1-100）、`context_window_tokens`（4096-1M）、`model`（非空字符串）
- 如果 `tools.my.allow_set` 为 false，则只能检查
