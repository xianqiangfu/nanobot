# 设置组件

本目录包含 WebUI 的设置相关组件。

## 组件说明

### SettingsView (`SettingsView.tsx`)

设置视图主组件，提供完整的设置界面。

## 设置类别

### 通用设置

- **语言设置** - 选择界面语言
- **主题设置** - 切换深色/浅色模式
- **字体设置** - 调整字体大小

### 聊天设置

- **默认模型** - 选择默认使用的 LLM 模型
- **最大轮次** - 设置单次对话的最大轮次
- **超时设置** - 配置请求超时时间

### 高级设置

- **调试模式** - 启用或禁用调试日志
- **API 配置** - 配置自定义 API 端点
- **代理设置** - 配置网络代理

## 组件特性

- **响应式设计** - 适配不同屏幕尺寸
- **即时生效** - 大部分设置更改立即生效
- **持久化** - 设置保存在 localStorage
- **国际化支持** - 支持多语言界面

## 使用示例

设置界面通常通过侧边栏的设置入口打开：

```tsx
import { SettingsView } from "@/components/settings/SettingsView";

<SettingsView />
```

## 数据流

1. 用户修改设置
2. 设置更新到 localStorage
3. 应用读取新设置并更新界面
4. 需要时发送配置到后端

## 注意事项

- 设置更改应该有适当的反馈
- 危险操作需要确认对话框
- 设置应该有默认值
- 设置界面应该清晰易用
