## 创建新的演示

1. **确定功能** - 选择要演示的功能
2. **准备场景** - 设计清晰的演示场景
3. **录制 GIF** - 使用录屏工具
4. **优化大小** - 压缩 GIF 文件
5. **测试显示** - 确保在各种环境中正常显示

## 录制工具

推荐使用的工具：

- **LICEcap** - 轻量级 GIF 录制
- **ScreenToGif** - Windows 平台
- **Kap** - macOS 平台
- **OBS Studio** - 专业录屏（可导出 GIF）

## 最佳实践

### 录制技巧
1. **保持简洁** - 演示时间控制在 10-30 秒
2. **清晰的操作** - 每个步骤都要清晰可见
3. **适当的速度** - 不要太快或太慢
4. **合适的区域** - 只录制必要的区域

### 文件大小
- 控制在 5MB 以内
- 使用适当的帧率（通常 10-15 fps）
- 优化颜色深度

### 视觉质量
- 确保文字清晰可读
- 使用高对比度
- 保持窗口大小一致
- 避免不必要的动画

## 注意事项

1. **隐私保护** - 不要在演示中暴露敏感信息
2. **一致性** - 保持演示风格一致
3. **更新** - 当功能变化时更新演示
4. **备份** - 保留原始录制文件
5. **测试** - 在不同设备上测试显示效果
