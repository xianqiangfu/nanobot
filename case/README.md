## Creating New Demos

1. **Identify Feature** - Choose the feature to demonstrate
2. **Prepare Scenario** - Design a clear demonstration scenario
3. **Record GIF** - Use screen recording tools
4. **Optimize Size** - Compress the GIF file
5. **Test Display** - Ensure it displays correctly in various environments

## Recording Tools

Recommended tools:

- **LICEcap** - Lightweight GIF recording
- **ScreenToGif** - Windows platform
- **Kap** - macOS platform
- **OBS Studio** - Professional screen recording (can export GIF)

## Best Practices

### Recording Tips
1. **Keep it concise** - Demo duration should be 10-30 seconds
2. **Clear operations** - Each step should be clearly visible
3. **Appropriate speed** - Not too fast or too slow
4. **Right area** - Only record the necessary area

### File Size
- Keep under 5MB
- Use appropriate frame rate (typically 10-15 fps)
- Optimize color depth

### Visual Quality
- Ensure text is clearly readable
- Use high contrast
- Keep window size consistent
- Avoid unnecessary animations

## Notes

1. **Privacy Protection** - Don't expose sensitive information in demos
2. **Consistency** - Maintain consistent demo style
3. **Updates** - Update demos when features change
4. **Backup** - Keep original recording files
5. **Testing** - Test display effects on different devices
